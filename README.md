# Aether AOT

Aether AOT — офлайн-анализатор Android-приложений на Flutter AOT, React Native Hermes и Unity IL2CPP.

Приложение работает прямо на Android-устройстве и не требует отправки APK на сторонние серверы.

## Возможности

- автоматическое определение Flutter AOT, Hermes и IL2CPP;
- анализ Flutter/Dart AOT;
- анализ React Native Hermes;
- анализ Unity IL2CPP;
- автоматическое извлечение необходимых файлов из APK;
- выбор подходящего встроенного анализатора для Flutter;
- отображение прогресса, времени и скорости анализа;
- сохранение результатов в выбранную пользователем папку;
- работа без root;
- работа без подключения к интернету;
- русский, украинский, белорусский и английский интерфейс;
- тёмная Black/OLED и светлая темы;
- несколько вариантов цветового оформления.

## Требования

- Android 8.0 и выше
- arm64-v8a
